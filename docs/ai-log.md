## Помилки та виправлення

| № | Помилка (фактичний вивід) | Причина | Виправлення |
|---|---|---|---|
| 1 | `npm warn install-scripts ... esbuild@0.28.2 (postinstall)` | npm 11 не виконує install-скрипти пакетів | esbuild працює без postinstall; попередження описано в skill build-and-test |
| 2 | `warning: The signature seems corrupted!` від postject на Windows | копія `node.exe` має підпис, який стає недійсним після вбудовування | спершу AI додав зняття підпису (~25 рядків); під час спрощення прибрано — це лише попередження, файл працює |
| 3 | `'ci.bat' is not recognized as an internal or external command` | cmd не шукає програми в поточному каталозі (`NoDefaultCurrentDirectoryInExePath`) | виклик з явним шляхом `.\ci.bat` |
| 4 | перевірка секретів не бачила нових файлів | на першому `init` увесь проєкт — ще не відстежувані файли | `git ls-files --cached --others --exclude-standard` |
| 5 | `ci.sh` потрапляв у Git без біта виконання | Windows, `core.filemode=false` | `git add --chmod=+x ci.sh` |
| 6 | помилка AI: у двох комітах кожен рядок README виглядав зміненим | текстовий stdout Python на Windows замінив `\n` на `\r\n` | коміти перероблено до публікації, запис байтів із LF |
| 7 | `check` проходив з `it.skipIf(true)`, `continue-on-error` у workflow і `npm test \|\| true` у `ci.sh` | перевірки дивилися лише на `.skip` | P3 — усі способи вимкнути тест; B2 — тест справді виконано; W4 — без `continue-on-error`; P4 — без `\|\| true` у `ci.sh` / `ci.bat` |
| 8 | версія Node.js у CI «плавала» (24.21.0 / 24.22.0) | `node-version: 24` бере версію з кешу runner | точна версія `24.20.0` у `ci.yml` |
| 9 | VS Code закреслює `todos` у `tools:` маніфесту | AI взяв стару назву набору інструментів | `todos` → `todo` (коміт `7cabdfa`) |
| 10 | структура перевантажена: у `develop` 47 файлів, у `feature` — 61 | AI ускладнив рішення понад вимоги методички | спрощення: `develop` — 17 файлів, `feature` — 30 (рішення 12) |
| 11 | зауваження агента: правило «файл відрізняється → `CONFLICT`» суперечило дописуванню README і `.gitignore`, а `ci.bat` після checkout має CRLF — повторний `init` на гілці `feature` зупинився б | у маніфесті були лише три статуси, вміст порівнювався з урахуванням кінців рядків | статус `UPDATED` для `README.md`, `.gitignore`, `.gitattributes`; порівняння без урахування CRLF/LF (коміт `52901eb`) |
